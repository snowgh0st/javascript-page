# JavaScript Page

A minimalist vanilla JavaScript project that demonstrates the simplest possible browser-based web app: one HTML page, one stylesheet, and one JavaScript file that displays a friendly greeting.

## ✨ Overview

This project is a clean starting point for learning the fundamentals of web development with:

- HTML for page structure
- CSS for presentation
- JavaScript for interactivity

It is intentionally small and easy to understand, making it a great first project for beginners or a quick reference for a simple static site.

## 🚀 What the App Does

When the page loads, the browser runs the JavaScript file and shows a classic "Hello, World!" alert.

## ▶️ Run It Locally

1. Open the project folder in your browser or use a simple local server.
2. Open `index.html` in a browser.
3. You should see the page and the JavaScript alert appear.

If you want to serve it locally with a tiny server:

```bash
python3 -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
